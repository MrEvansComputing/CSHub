# CS Spec Hub — Years 9, 10 and 11

This is the combined GitHub Pages version of the CS Spec Hub.

## Upload once to GitHub

Upload the **contents of this folder** to one GitHub repository.

The structure is:

- `/index.html` — main year selector
- `/year9/` — Year 9 site
- `/year10/` — Year 10 site
- `/year11/` — Year 11 site

## GitHub Pages

1. Create one repository, for example `cs-spec-hub`.
2. Upload all files and folders from this package.
3. Open **Settings → Pages** in the GitHub repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing the files (normally `main`) and `/ (root)`.
6. Save.

GitHub Pages will then serve:

- `.../cs-spec-hub/`
- `.../cs-spec-hub/year9/`
- `.../cs-spec-hub/year10/`
- `.../cs-spec-hub/year11/`

Each year keeps its own local progress/XP storage key, so progress does not interfere between year groups.
