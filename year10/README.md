# Year 10 CS Spec Hub

Emerald/green Year 10 version of the CS Spec Hub.

## Structure
- 6 specification areas
- 39 subtopics
- 195 interactive activities/challenges
- Learn → Practise → Apply → Master progression
- local XP and task progress saved in the browser
- static HTML/CSS/JS suitable for GitHub Pages

## Main areas
1. Algorithms
2. Programming
3. Data
4. Computers
5. Networks
6. Security & Impact

The Year 10 tasks deliberately move beyond Year 9 recognition into application, diagnosis, calculations, comparison, debugging and justification.
