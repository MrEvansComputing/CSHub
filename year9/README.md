# Year 9 Computer Science Spec Hub

A static GitHub Pages learning and revision site built around the Year 9 content in the school's KS4 scheme of work and the Pearson Edexcel GCSE Computer Science specification.

## Design
The site is organised by specification topic rather than term/week, so teaching order can change without breaking the resource.

Top-level areas:
- Computational Thinking
- Algorithms
- Truth Tables
- Programming Fundamentals
- Networks
- Data Representation

Each subtopic includes:
- concise teaching notes
- worked example
- multiple activity types
- immediate feedback
- XP/progress stored in localStorage
- an open-ended mastery challenge

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, `data.js` and `app.js` to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/ (root)`.

No build process or external packages are required.
